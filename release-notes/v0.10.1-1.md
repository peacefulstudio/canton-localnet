# canton-localnet v0.10.1-1

The vendored Splice moves to 0.10.1 and the Canton inside to 3.7.2, and the fixtures drop the party display name and gain the gRPC Ledger API address.

## Upgrading

- **Party allocation has no `displayName`.** Canton's JSON API ignores it, so the .NET `PartyAllocator`, `LocalnetFixture` and `ValidatorFixture` allocation methods and the Go `PartyAllocator.Allocate` and `AllocateParty` lose the argument. Drop it at each call site.
- **`UploadAndVerifyAsync` is removed.** `DarUploader.UploadAndVerifyAsync`, the two fixtures' `UploadAndVerifyDarAsync` and `JsonLedgerAdminClient.PackageExistsAsync` are gone. `UploadAsync` does the verification now.
- **`LocalnetEndpoints` has a new positional parameter.** `GrpcLedgerApi` follows `JsonLedgerApi` in the .NET record's constructor.

No volume wipe is needed: the protocol version stays 37. `docs/public/MIGRATION.md` carries the same steps.

## What's new since v0.10.0-1

**Splice 0.10.1 on Canton 3.7.2.** A patch bump: ports, slots, env-var names and auth are unchanged, and the Splice images move to base image 1.0.19. The validator's `synchronizer-topology.num-parties` metric now counts parties hosted on no participant, and wallet sweeps use token standard transfers. The Hetzner LocalNet VM wipes its volumes on the version change by itself.

**A PQS connection URI.** `canton-localnet env --pqs` and the action's `pqs: true` also export `CANTON_LOCALNET_<SLOT>_PQS_URL`, a libpq URI that `psql` and the Rust SDK can read. The action masks it like the password, and the log filter now also redacts the password of any `scheme://user:password@host` URI.

**Boot failures name the stalled containers.** When the boot action fails, its log lists every unhealthy, restarting or exited container with the last 50 lines of its log, redacted.

**The gRPC Ledger API address in both fixtures.** `LocalnetEndpoints.GrpcLedgerApi` (.NET) and `Endpoints.GRPCLedgerAPIURL` (Go) default from the slot's port prefix, and `CANTON_LOCALNET_<SLOT>_GRPC_URL` overrides them.

**Fixtures clean up after themselves.** Both fixtures delete the ledger users they created on dispose, and DAR uploads check vetting through `/v2/dars`, on every connected synchronizer in Go.

**A shorter README.** The README is a landing page, with the long sections on topic pages under `docs/public/`. The action snippets pin by release tag.

**A hardened stack.** Every image is pinned by tag and digest, the Grafana anonymous role is `Viewer`, and a validator set to `off` no longer publishes host ports.

## Fixed

The fixtures retry transient `503`, `504` and `409` statuses the same way in both languages and fetch a fresh token per attempt. `canton-localnet wait-ready` keeps the last real error when its deadline cuts the final probe, polls every enabled slot, and fails when a node container restarted during boot. The full list is in the [CHANGELOG.md](https://github.com/peacefulstudio/canton-localnet/blob/v0.10.1-1/CHANGELOG.md).
