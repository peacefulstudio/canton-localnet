# canton-localnet v0.10.0-1

The vendored Splice moves to 0.10.0 and the Canton inside to 3.7.1, which changes the default protocol version, so an existing stack must recreate its volumes.

## Upgrading

- **Recreate your volumes.** Splice 0.10.0 bootstraps the global synchronizer on protocol version 37 instead of 36, and the protocol version is only chosen when a synchronizer is first created. Run `canton-localnet down --volumes` before `canton-localnet up` on any stack that holds data from an earlier release. Ledger state, onboarded parties and uploaded DARs do not survive the wipe. The Hetzner LocalNet VM wipes its volumes on the version change by itself.
- **`NGINX_VERSION` must name an `nginx/nginx-unprivileged` tag.** The `nginx` and `nginx-keycloak` containers now run `nginx/nginx-unprivileged:1.30.6-alpine-slim`, pinned by digest, as a non-root user. An override naming a tag of plain `nginx` no longer resolves. A config you mount into either container must listen on a port above 1023 and keep its pid file in a writable path such as `/tmp`.
- **Mounted validator configs need two edits.** Splice 0.10.0 reads a validator's participant admin endpoint from `participant-client.admin-api.client-config`, and refuses to start without an explicit `participant-client.admin-api.auth-config`. Rename `participant-client.admin-api.port` to `participant-client.admin-api.client-config.port` and add `participant-client.admin-api.auth-config.type = "none"`.
- **The `vm` command group is gone.** Use `canton-localnet tunnel --host <host>` for the tunnel; the AWS `vm provision` and `vm destroy` verbs are removed.
- **Go fixture endpoint defaults changed.** The Keycloak host default is now `localhost` and the scope default is `openid`. Set `CANTON_LOCALNET_KEYCLOAK_HOST=keycloak.localhost` to keep the old host. `For(RoleSvValidator1)` now needs `CANTON_LOCALNET_SV_VALIDATOR_1_TOKEN_URL`, `_CLIENT_ID` and `_CLIENT_SECRET` and returns an error naming them when any is missing.

`docs/public/MIGRATION.md` carries the same steps.

## What's new since v0.9.4-1

**Splice 0.10.0 on Canton 3.7.1.** The stack boots on Splice 0.10.0 with Canton 3.7.1 inside, and PQS moves to scribe 3.7.0, the first scribe built for Canton 3.7. Postgres moves from the floating `postgres:18` tag to `18.6-trixie`, pinned by digest. Ports, slots, env-var names and auth are unchanged.

**`CANTON_PROTOCOL_VERSION` is effective again.** Splice 0.10.0 dropped the setting the variable used to drive, so on a fresh stack it silently did nothing. It now sets the initial protocol version of the `sv-validator-1` configuration. It still applies to fresh volumes only.

**Health probes cover `c-validator-1`.** The `canton` and `splice` container health checks now probe `c-validator-1` when the slot is on, so a dead participant or validator app on that slot makes its container unhealthy instead of going unnoticed.

**`wait-ready` detects a crash-looping `splice` container.** Instead of running to its timeout, it stops early when the container restarts on a known fatal startup line, starting with a postgres volume bootstrapped with a different party hint than the configured one. The error names the hints and the remedy (`canton-localnet down --volumes`).

**A top-level `tunnel` command.** `canton-localnet tunnel --host <host>` opens the `ssh -L` forward to a remote LocalNet for the eight LocalNet ports, with `--user` defaulting to `root`. It needs no repository checkout and no terraform.

**The Go fixture discovers endpoints like the C# fixture.** `EndpointDiscovery.For` reads the per-slot `CANTON_LOCALNET_<SLOT>_JSON_API_URL`, `_TOKEN_URL`, `_AUDIENCE` and `_SCOPE` variables first, then falls back to the host and port composition and the global values.

**Curated release notes.** Each release now publishes a hand-written body like this one, while `CHANGELOG.md` stays the exhaustive log.

**The AWS path is retired.** The AWS terraform stack at the root of `terraform/` is removed. The Hetzner stack stays: bring it up and down with `make hetzner-up` and `make hetzner-down`.
